# 判断の記録

追記だけにする。

## 2026-10-17 始めたときの仮決定

- **Windows の常駐は C++ / Win32 / Direct2D、設定画面は別プロセスの WinUI 3**: 本人の「無用にリソースを消費しない」と「ネイティブ UI で描画」を両立させるため。WinUI 3 や .NET を常駐側に入れると、絵が小さくても数十MBを持ち続ける。設定画面は開いている間だけなので WinUI 3 にした
- **Mac は Swift の1つのアプリ**: SwiftUI / AppKit は常駐させても軽く、分ける利点が薄い
- **OS の画像の仕組み（WIC・ImageIO）で読む**: 自前の GIF の読み込みや共通のライブラリを持たない。2つの OS で共有するのは設定の JSON の形と `SPEC.md` だけ
- **通知領域・メニューバーのアイコンも既定で出さない**: 本人の「アイコンが出っぱなしにならない」を強めに取った。設定画面はもう一度起動すると開く。出したい場合は設定で出せる。本人に確認する
- **名前は pixwall（仮）**

## 2026-10-17 解像度の変化とメニューバーの下

- **解像度が変わったら自動で合わせる**: 本人は解像度をよく変える。OS が変化を知らせてくれるので、そのときだけ計算し直せば重くならない。見張り続ける方法は取らない。自動で合わないときのために、手で「表示を更新」もできるようにする（本人の要望）
- **倍率は物理ピクセルで計算する**: 拡大率が変わったときにドットの大きさが不ぞろいになったり、ぼやけたりしないため
- **Mac はメニューバーの下も、Windows はタスクバーの下も描く**: 本人の要望。ほかのアプリはメニューバーの下が描かれず、半透明・透明なメニューバーだと浮いて見える。原因はたぶん `visibleFrame` を使っていることか、`NSWindow` が自分で位置を直すこと。`frame` を使い、`constrainFrameRect` を上書きする

## 2026-10-17 Mac の OS の壁紙にも1枚目を入れる

- 本人が「入れてほしい」と決めた。Mission Control や、壁紙からメニューバーの色を決める macOS で見た目をそろえるため
- OS に拡大させるとドットがぼやけるので、pixwall が画面の解像度の PNG に描いてから入れる
- 本人の元の壁紙を書き換えるので、元の値を覚えて、外したとき・終えたときに戻す

## 2026-10-17 静止画を書き出すボタン

- 本人の要望。pixwall が動いていないときにも、静止画でよいので同じ見た目を壁紙にしたいため。Windows・Mac の両方の設定画面に置く
- Mac で OS の壁紙に入れる PNG と同じ描き方を使う。書き出すフレームは選べる（既定は1枚目）
- Windows は並べ方の計算を常駐側と設定画面で二重に持たないよう、C++ の部分を DLL に分けて設定画面からも呼ぶ（仮）

## 2026-10-17 Mac 版の最小の形

- **Xcode のプロジェクトを持たず SwiftPM にした**: `.xcodeproj` は差分が読みにくく、Linux 側で書いて Mac でビルドする流れに向かない。`.app` は `build-app.sh` で包む。`Info.plist` の `LSUIElement` に加え、コードでも `setActivationPolicy(.accessory)` にして、`.app` にせず動かしたときも Dock に出さない
- **画面ごとに窓とタイマーを1つずつ持つ**: 今は全画面に同じ画像だが、後で画面ごとに別の画像・別の止める条件（隠れているか）になるため。フレームの `CGImage` は窓どうしで共有する
- **MacBook Air M1（macOS 27、Xcode 27 beta 2）で確かめたこと**: 64×64・30フレーム・100ms の GIF を「整数倍で最大」で1画面に出して、CPU 0.0〜0.3%、メモリ 9.5MB（`top` の MEM）。目安（0.5% 未満・30MB 未満）に収まる。メニューバーの下・Dock の下まで描け、ウィジェットとアイコンは手前に出る。Dock にアイコンは出ない
- **まだ確かめていないこと**: ほかの窓で全部隠れたときに止まるか（`occlusionState` がデスクトップの高さの窓でも変わるか）、画面の消灯・ロック・低電力モードで止まるか、解像度を変えたときの作り直し、Mission Control・操作スペースの切り替え
- **`.app` を `~/Documents` の中から起動すると「書類フォルダへのアクセス」の許可を求められた**: 画像は `~/Library/Application Support/pixwall/` に置いていても出た。`.app` を `~/Applications` に置いて起動すると出ない（1回目の画面は残っていたので、2回目以降に出なかったかは画面だけでは言い切れない）。試すときは `~/Applications` に置く
